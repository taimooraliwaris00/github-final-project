# Simple Interest Calculator

A lightweight Bash command-line tool designed to calculate simple interest based on principal amount, annual interest rate, and time period.

## Description

This project contains a Shell script (`simple-interest.sh`) that interactively prompts the user for financial inputs and computes the simple interest earned or owed over time.

## Formula

Simple Interest is calculated using the formula:

$$\text{Simple Interest} = \frac{P \times R \times T}{100}$$

Where:
* **$P$**: Principal amount (initial investment or loan amount)
* **$R$**: Annual interest rate (percentage)
* **$T$**: Time period (in years)

## Prerequisites

* Unix-like environment (Linux, macOS, WSL, or Git Bash)
* Bash shell
