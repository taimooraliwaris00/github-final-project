# Contributing to Simple Interest Calculator

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

1. **Fork the Repository:** Create a copy of this repository on your GitHub account.
2. **Clone the Fork:** Download the repository to your local machine using `git clone`.
3. **Create a New Branch:** Use `git checkout -b feature-name` to create a working branch.
4. **Make Changes & Commit:** Keep your commits small and write clear commit messages.
5. **Push Changes:** Upload your branch to GitHub using `git push origin feature-name`.
6. **Submit a Pull Request:** Navigate to GitHub and open a pull request against the main branch.
